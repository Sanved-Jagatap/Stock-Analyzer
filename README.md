# Stock-Analyzer
A powerful Streamlit-based web application for interactive stock market analysis. This tool fetches historical stock data and provides insightful visualizations and technical indicators such as RSI, SMA, EMA, Bollinger Bands, and Linear Regression-based trend analysis.

Features:
 Fetches historical stock data using yfinance

Calculates and visualizes:
Simple Moving Average (SMA)
Exponential Moving Average (EMA)
Relative Strength Index (RSI)
Bollinger Bands
Risk-to-Reward Ratio
Linear Regression trendlines with slope interpretation

Saves data to an SQLite database for persistence

Offers downloadable CSV files of analyzed data

Supports multi-stock comparison on a single chart

Fully interactive UI using Streamlit

Tech Stack:
Frontend & UI: Streamlit
Data Handling: pandas, yfinance
Visualization: matplotlib

Machine Learning: scikit-learn (Linear Regression)

Database: SQLite

Backend Logic: Python
